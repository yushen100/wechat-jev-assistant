# 微信 Jev 对话助手部署指南

本文面向获得私有仓库访问权限的 Windows 用户。程序在使用者自己的电脑上运行，不需要部署服务器。

## 1. 环境要求

- Windows 10 或 Windows 11
- Python 3.12（64 位）
- Git
- 微信桌面版
- TypeSafe API Key

建议使用普通 Windows 用户运行。只有数据库读取因系统权限失败时，才分别检查微信和助手是否处于相同权限级别。

## 2. 获取项目

### 2.1 通过 Releases 安装（推荐）

1. 打开仓库的 [Releases](https://github.com/yushen100/wechat-jev-assistant/releases)。
2. 下载最新的 `wechat-jev-assistant-版本-windows.zip` 和对应的 `.sha256` 文件。
3. 把两个文件放在同一目录，在 PowerShell 中校验：

```powershell
Get-FileHash .\wechat-jev-assistant-0.1.0-windows.zip -Algorithm SHA256
Get-Content .\wechat-jev-assistant-0.1.0-windows.zip.sha256
```

两个 SHA-256 值必须一致。校验通过后，把 ZIP 解压到非系统盘的独立目录，再执行 `setup.ps1`。

### 2.2 通过 Git 克隆

使用 GitHub 已授权账号执行：

```powershell
git clone https://github.com/yushen100/wechat-jev-assistant.git
cd wechat-jev-assistant
```

仓库为私有状态时，未被邀请的账号无法克隆。

### 2.3 通过 GitHub Packages 安装

GitHub Packages 中发布的是 NuGet 包，适合脚本化部署。私有包要求 GitHub Personal Access Token 具备 `read:packages` 权限；不要把 Token 写入项目或提交记录。

先安装 NuGet CLI，然后添加私有源：

```powershell
nuget sources Add `
  -Name GitHub-yushen100 `
  -Source https://nuget.pkg.github.com/yushen100/index.json `
  -UserName yushen100 `
  -Password "自己的GitHub Token"
```

安装指定版本：

```powershell
nuget install WechatJevAssistant `
  -Version 0.1.0 `
  -Source GitHub-yushen100 `
  -OutputDirectory .\packages
```

程序文件位于 `packages\WechatJevAssistant.0.1.0\tools`。进入该目录后继续执行 `setup.ps1`。

对普通用户，优先使用 Releases ZIP；NuGet 包主要用于自动化和集中部署。

## 3. 安装依赖

在项目目录打开 PowerShell：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\setup.ps1
```

安装脚本会：

1. 创建项目独立虚拟环境 `.venv`。
2. 从可信镜像安装 Python 依赖。
3. 按固定提交下载微信数据库读取依赖。
4. 保持发送、监听、UIA 热激活、媒体下载和密钥文件写出功能不可用。

如果下载 GitHub 依赖失败，可在确认本机代理已经运行后临时设置：

```powershell
$env:HTTPS_PROXY = "http://127.0.0.1:7897"
$env:HTTP_PROXY = "http://127.0.0.1:7897"
.\setup.ps1
```

## 4. 配置 TypeSafe API Key

每位使用者必须使用自己的 TypeSafe API Key。不要把 Key 写进源码、配置文件、聊天消息或提交记录。

在 PowerShell 中设置当前 Windows 用户环境变量：

```powershell
[Environment]::SetEnvironmentVariable(
    "TYPESAFE_API_KEY",
    "在这里填写自己的Key",
    "User"
)
```

设置完成后，重新登录 Windows，或者彻底关闭并重新打开终端和助手。

## 5. 启动

双击：

```text
0921_启动微信Jev助手_v1.cmd
```

也可以在项目目录运行：

```powershell
.\.venv\Scripts\pythonw.exe .\main.pyw
```

程序默认常驻系统托盘，并注册 `Ctrl+Alt+J` 全局快捷键。

## 6. 首次使用

1. 登录微信桌面版。
2. 打开需要分析的聊天，并让微信保持在前台。
3. 在助手中点击“区域校准”，拖动框选微信聊天区域。
4. 回到目标聊天，按 `Ctrl+Alt+J`。
5. 助手识别当前会话，从本地数据库读取最近 100 条文字消息，脱敏后提交分析。

每台电脑的分辨率、缩放比例和微信窗口布局可能不同，因此每位使用者都应独立校准。

## 7. 本地数据与隐私

- `data/` 保存本机配置、加密历史和 Windows DPAPI 保护的密钥。
- `logs/` 保存运行日志，但不应记录 API Key 或聊天正文。
- 截图只用于识别当前会话标题，不保存到磁盘。
- 手机号、邮箱、身份证号、银行卡号和 URL 查询参数会在本地脱敏。
- 脱敏后的对话文本会发送到 TypeSafe API。
- 不要把 `data/`、`logs/`、`.env` 或任何 Key 上传到 GitHub。

## 8. 更新

### Git 安装方式

先退出助手，再在项目目录执行：

```powershell
git pull --ff-only
.\setup.ps1
```

`data/` 和 `logs/` 不受 Git 更新影响。

### Release 安装方式

1. 退出助手。
2. 下载并校验新版本 ZIP。
3. 解压到新的版本目录。
4. 把旧目录中的 `data/` 复制到新目录；不要复制 `.venv/` 和 `logs/`。
5. 在新目录重新运行 `setup.ps1`。
6. 确认历史可读后，再决定是否删除旧版本目录。

### NuGet 安装方式

用新的版本号再次执行 `nuget install`，进入新版本的 `tools` 目录运行 `setup.ps1`。NuGet 不会自动迁移本地 `data/`。

## 9. 发布者操作

项目维护者创建版本标签后，GitHub Actions 会自动：

1. 生成不含私人目录的 Windows ZIP。
2. 生成 SHA-256 校验文件。
3. 构建并发布 `WechatJevAssistant` NuGet 包。
4. 创建 GitHub Release 并上传三个产物。

发布示例：

```powershell
git tag -a v0.1.0 -m "v0.1.0"
git push origin v0.1.0
```

## 10. 验证安装

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -q
```

看到 `OK` 表示核心测试通过。测试通过不代表当前微信版本一定兼容，仍需实际打开一个聊天验证读取功能。

## 11. 常见问题

### 提示缺少 `TYPESAFE_API_KEY`

确认环境变量设置在当前 Windows 用户下，并重启助手。不要把 Key 粘贴到 Issue 或日志中。

### 找不到当前会话

保持微信目标聊天位于前台，重新执行区域校准，并确认框选区域包含顶部会话标题。

### 数据库读取失败

确认微信已登录、助手和微信权限级别一致，并检查当前微信版本是否仍被固定数据库依赖支持。

### 快捷键没有反应

检查 `Ctrl+Alt+J` 是否被其他软件占用，也可以从托盘打开助手后点击“重新分析”。

### 安装下载超时

优先重试一次；在中国网络环境下，可启用本机 Clash 代理 `http://127.0.0.1:7897` 后重新运行安装脚本。

## 12. 卸载

1. 从托盘退出助手。
2. 如果启用了开机启动，先在助手设置中关闭。
3. 删除项目目录。

删除 `data/` 会永久删除本机加密分析历史。需要保留历史时，应先备份整个 `data/`，且备份只能由原 Windows 用户正常解密。
